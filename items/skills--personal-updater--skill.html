Personal Updater

会話中の採用・拒否・修正から、本人の判断基準を継続的に学ぶ。

Skill: Personal Updater

Goal

会話ログを保存することではなく、将来の判断を改善するContextを育てる。

Signals

  • ACCEPT: いい / それ / 採用 / これで
  • REJECT: 違う / つまらない / 使えない / そうじゃない
  • REVISION: もっと〜 / 〜は残して / 〜だけ変えて
  • REPEAT: 同じ要求・不満が別タスクでも再登場
  • BEHAVIOR: 本人が実際に選んだ/使った/公開した結果

Extraction

各signalから以下を候補化:

  • situation
  • proposed_or_existing_behavior
  • user_response
  • inferred_rule
  • confidence
  • evidence_count
  • scope
  • contradiction

Promotion

1回の反応だけで人格ルールにしない。

  • local/project rule: 明示的修正なら1回でも候補化可
  • general preference: 原則2件以上の独立 evidence
  • core decision policy: 複数domainで繰り返す、または本人が明示

Update targets

  • FACTS: 安定した事実
  • MIND: 判断基準・優先順位
  • VOICE: 媒体別の表現
  • PROJECT: そのProject固有
  • SKILL/EVAL: 「好み」ではなく工程改善ならこちら

Never promote

  • 一時的な気分
  • センシティブ情報
  • 第三者PII
  • AI側の推測だけ
  • 単発の作品固有修正を全人格へ一般化したもの
