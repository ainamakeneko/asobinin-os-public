System

Daily Knowledge Update

新しい情報をProjectと照合し、使い道のある知識だけKnowledge候補へ変換する。

Skill: Daily Knowledge Update

Trigger

定期実行、または「最近何か使えそうなものある？」。

Procedure

1. active projects / decision policy / existing knowledgeの見出しを読む。

2. 各カテゴリの最新情報を一次情報優先で収集する。

3. relevanceを判定する。

4. 既存knowledgeと重複・矛盾・陳腐化を確認する。

5. candidateを作る。

6. Criticが evidence / novelty / actionability を検査する。

7. 合格したものだけKnowledgeへの追加・更新案にする。

8. Knowledge Mapを再生成する。

Relevance

次のどれかが明確なら候補:

  • active projectの次の判断を変える
  • 今できなかったことを可能にする
  • 人間作業を減らせる
  • model / tool / API変更で既存Skillに影響する
  • 新しい制作実験につながる
  • 既存knowledgeを訂正する

単なる話題性、一般的AIニュース、似た内容の言い換えは保存しない。

Output

candidateには source / date / claim / why_it_matters / affected_projects / suggested_action / confidence を必須にする。
